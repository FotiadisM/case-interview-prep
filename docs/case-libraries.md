# Case Libraries & Downloads

The classic free practice corpus: MBA consulting-club casebooks (full interview transcripts with interviewer notes and model answers) plus the firms' own official cases. Use them for *volume* — read the interviewer notes, not just the exhibits. Rep counters: aim for 15–25 full cases total, of which 5–8 profitability (HackingTheCaseInterview's recommendation), then keep drilling weak spots.

## Downloadable casebooks (included in this site)

These four PDFs ship with this playbook:

- [Kellogg 2020 casebook](/casebooks/Kellogg_2020.pdf) — broad industry coverage, useful interviewer-note sections
- [MIT Sloan 2020 casebook](/casebooks/MIT_Sloan_2020.pdf) — deep quant-heavy cases
- [Tuck 2024 casebook](/casebooks/Tuck_2024.pdf) — recent vintage, close to current interview style
- [Yale 2013 casebook](/casebooks/Yale_2013.pdf) — classic variety, good for fundamentals

**How to use them:**
1. Print one case; skim the prompt; solve it aloud with a timer (35 min).
2. Open the interviewer notes and compare; score yourself on the five dimensions in [Case Interview Basics](/case-interview-basics).
3. Log the failing dimension; convert it into next week's drill.

## Building your own library

Sort cases by: (1) case type, (2) firm style (interviewer-led / candidate-led), (3) difficulty. Never re-solve a case you've seen the answers to — keep an unsolved queue for mocks, solved ones for reference.
